# 数据库迁移

0000 为 Drizzle schema 首迁移，包含 Better Auth 1.7.14 核心表及课程、进度、邀请、限流和私有本地测试邮件表。0001 为独立占位课程数据迁移，不创建用户或个人完成进度。

使用 npm run db:generate 生成 schema 变更；自定义数据迁移先使用 drizzle-kit generate --custom --name 名称，再填 SQL，保持 journal 和 snapshot 顺序一致。不要更改已执行的迁移。

本地执行 npm run db:migrate:local。远程必须显式 --remote 并确认环境；CI 不迁移云数据库。D1 无交互式事务，业务原子性使用单语句或 batch。

集成测试真实执行所有迁移；上线仍需备份与向前修复／恢复演练。

0002 为无邮箱账号迁移：新 email 可 NULL，增加别称／待激活状态及凭证／审计表。为避免 D1 级联删除，先保存并移除子表、重建 user、恢复账号与进度；旧会话有意撤销。旧成员使用原 ID 重新激活，不重建进度。0003 为用户／会话增加凭据版本。

0004 新增线下考核尝试、审核、奖励授予表及进度／奖励设置版本，不重建已有父表或更改旧记录。已有通过状态不会被补造审核历史或奖励；新通过才生成相应记录。新增外键保护考核及发奖历史，后续注销应采用归档或专门设计的清理流程，不能直接级联删除有业务历史的用户。

0005 为章节增加 sort_order、可选文字 icon 和 status（draft／published／archived），保留已有章节为 published 以延续占位课程浏览。仅执行 ADD COLUMN，不重建父表、不修改任何任务 ID 或个人历史。当前服务端只返回 published 章节及其未归档任务；新增字段不等于已实现网页发布。

0006 仅向 chapter 新增 JSON 展示配置 presentation，另建独立 course_asset 元数据表；不重建或清空旧任务／用户／进度父表。素材默认 draft，只有被可浏览课程引用的合法 published 条目可通过成员课程响应返回。该表不存图片字节，也不代表已提供上传或私有文件存储。

0007 新增 content_permission、course_revision 与 course_change，初始化课程版本为 0；不授予任何现有账号权限，不重建或清空旧表。课程保存即生效，版本与修改快照同批原子写入。历史 draft 章节在编辑器映射为归档，未明确恢复不会自动公开。

0008 仅新增 course_quest_deletion 保存受控删除的任务快照、操作者、时间、课程版本及不可复用的 ID；不重建父表，不删除任何现有任务或业务历史。实际删除由保存接口在无进度／考核／奖励且无剩余依赖时原子执行，外键继续保护业务历史。

0009 仅新增 video，记录 B2 对象归属、固定版本、预留大小、考核尝试及删除状态／操作者；外键使用 NO ACTION，不重建或清空任何账号、密码、进度、考核或奖励父表。无旧 R2 对象迁移；本次执行范围仅为测试临时 D1，真实环境需在部署前执行迁移。

0012 仅新增 course_chapter_deletion 保存受控删除的章节快照、操作者、时间与课程版本；实际删除由保存接口在章节内任务均无进度／考核／奖励且无外部前置引用时原子执行，同时保留本章任务的删除快照，不重建父表或删除业务历史，旧章节与任务 ID 不得复用。
