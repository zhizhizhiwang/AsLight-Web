## 2026-10-29：UI/UX 第一项实施

成员接口返回按顺序排列的可浏览章节和完整任务图谱；章节标题、文字图标及顺序来自数据库。流程图／列表／主页面沿用同一章节，URL 使用 `chapter`、`kind`、`quest`，兼容原有只含任务 ID 的链接。详情解释跨章节前置并可跳转，不在当前章复制外章节点。空章节、无章节、无效／归档引用有明确提示。

0005 仅向 chapter 增加顺序、文字图标和可见状态，不重建父表或修改任务、个人进度及考核／奖励历史。草稿与归档章节不会进入成员课程接口；这些字段只是浏览过滤基础，不代表已实现草稿编辑或版本发布。

验证：14 项领域／API／导航测试、生产构建和体积检查、2 组真实本地 Worker/D1 集成通过；桌面及 390 × 844 浏览器视口检查了章节切换、空章节、节点／跨章前置、缩放和详情关闭。桌面还验证了列表／概览沿用章节、浏览器返回恢复及焦点返回。手机宽度由隔离预览中的固定尺寸框架模拟，未验证真机触摸手势。

上述记录对应第一项的验收；后续实施见下方更新。

## 2026-10-29：章节设计与即时保存

管理员单独授予／撤销已激活账号编辑能力，管理员自己也不默认获得编辑权。按用户后续要求取消草稿／发布流程，保存经完整校验后原子生效，其他人刷新查看。课程版本拒绝并发覆盖，网络重试幂等，修改保留人员／时间／原因和内容快照。已有学习记录的任务不能直接修改前置和考核要求，应新增任务并归档旧任务。0007 只新增表，不改写旧业务历史或自动授权。
