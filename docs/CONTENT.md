# 课程展示数据

当前支持网页编课与即时保存。正式图片、教学与考核正文由用户提供；已有课程没有配置时保持原有占位名称和说明。内容人员在 `/content` 使用表单编辑，不需要日常修改代码、SQL 或重新部署。管理员在成员管理中单独授予编辑权限。

## 素材引用

`course_asset` 保存稳定 id、path、alt、width、height 和 status（draft／published／archived）。目前仅接受 `/course-assets/` 下预先审核并公开部署的 PNG、JPEG、WebP、AVIF 或静态 SVG；文件名只允许字母、数字、下划线、连字符及目录分隔符。不接受外部 URL、data URL、查询令牌、目录穿越或成员作业路径。尺寸为 1–8192 像素，替代说明不能为空。

成员响应中的 assets 只含可浏览课程实际引用的合法 published 元数据，不含状态或未发布路径。无效／未发布／缺失引用不会使文字说明消失；普通图文显示替代提示，任务和章节标记退回文字／默认图标，缺失背景不显示。已发布文件加载失败也提供相同回退。

**登记表不保存文件，也不提供上传。** 仅可在公开静态目录放入已公开课程图片；将登记状态改为 draft 不能收回已部署的静态文件。未公开图片、成员作业、凭证及其他私有数据不得放入公开目录。编辑器只能选择已登记的合法公开素材，保存时检查引用；上传、文件属性检查、替换与清理需另行实现。不设置课程发布流程。

## 章节展示配置

chapter.presentation 为受控 JSON，默认 `{}`；支持以下可选字段：

- iconAssetId：章节图片图标；未配置或缺失时使用原文字图标／顺序。
- backgroundAssetId：固定在画布下方的低对比度背景，不拦截操作。
- viewport：初始 x、y 与 zoom；zoom 范围 0.35–2。手机优先聚焦首个任务以保持可点击尺寸，按类型筛选后重新聚焦任务。
- decorations：最多 100 个图片或文字元素，每项包含唯一 id、position、width、height、layer 和对应内容。图片使用 assetId／alt；文字使用 text。layer 为 0–20，仅决定装饰之间的顺序，所有装饰都在任务和必要连线下方。

坐标范围为 -100000–100000，尺寸必须大于零且不超过 8192。装饰随世界坐标平移／缩放，不参与前置关系、任务总数或个人学习状态，不响应指针操作，也不扩大“回到合适视野”的计算范围。成员仍不能拖动修改节点。

## 任务图文

任务 definition 可附 imageAssetId、content 和 assessmentContent。图片标记在图谱、列表和详情共用；content 为空时显示原 summary，考核内容为空时不显示相应区块。

内容块按数组顺序渲染，最多 100 项，只支持以下类型：

| type      | 字段                       | 显示           |
| --------- | -------------------------- | -------------- |
| heading   | text                       | 内容内小标题   |
| paragraph | text                       | 保留换行的段落 |
| list      | ordered、items             | 有序／无序列表 |
| image     | assetId、alt、可选 caption | 图片与说明     |

标题上限 200 字符；段落和单条列表文字上限 10000 字符；每个列表 1–100 项；图片替代说明上限 300 字符，说明文字上限 500 字符。文字由 React 转义，不解析 HTML、Markdown、脚本、任意 CSS 或外部嵌入。未知内容块及非法章节结构在保存前拒绝。

这些字段只承载展示，不增加考核机制。任务身份、已通过结果和奖励由服务端保留。更改学习要求遵循 [DOMAIN](DOMAIN.md) 的约束；当前对已有学习记录的任务拒绝修改前置或考核内容。

## 即时编辑协议

`GET /api/content/access` 返回独立编辑能力；`GET /api/content/course` 返回完整编辑文档、可选公开素材与版本。`POST /api/content/course` 提交 expectedRevision、requestId、reason 和完整 document；最大请求 256 KiB，最多 200 章／1000 任务。编辑文档不允许传入奖励设置、个人进度或账号角色。

保存校验全部启用任务的 DAG、章节归属、图片引用和结构。已有稳定 ID 不可从文档移除，使用 archived 隐藏。旧 draft 章节在编辑器按归档处理，只有明确恢复并保存才可浏览。成功后立即整体生效，无提交审批或发布步骤。服务端版本比较与批量写入原子执行，权限在写入点再次校验；相同请求重试不会新增版本。`course_change` 留存修改者、时间、原因及整份课程快照，目前无历史浏览或回滚界面。

未保存修改仅保留在当前页面内存，切换站内子页后返回仍保留；关闭／刷新页面会提示，不提供离线持久草稿。桌面与手机预览复用实际图谱、图文与详情组件，但不读取或写入个人学习数据。预览中的图片仍来自已公开课程素材。

## 画布编排

章节设计以画布为主，左侧选择章节，点任务打开属性；成员端的图谱保持只读。画布工具提供放置任务、视野中心新增、框选、连接前置、复制选中及装饰移动；右键空白处也可在该位置新增。触屏及键盘可用可见按钮，前置可依次点选两个任务，方向键移动选中任务，Shift 配合方向键微调。窄屏属性使用可关闭的原生弹层。

移动只改变位置，使用整数坐标并校验范围；任务身份及学习历史不变。复制生成新任务 ID，组内前置改指向对应副本，组外前置保留；不会复制个人进度或奖励登记。连接方向为“前置任务 → 后续任务”，自连、重复或循环在客户端提前处理，保存仍由服务端最终校验。跨章节前置也可在属性面板选择。

属性和装饰定位使用已有结构，不开放任意脚本／样式；保存方式和独立编辑权限保持不变。2026-10-30 的画布实际操作与窄屏视觉验收尚待补充，不能沿用旧表单界面的截图和操作验证作为新交互已通过的证据。
