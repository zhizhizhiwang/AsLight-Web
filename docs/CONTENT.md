# 课程展示数据

当前支持网页编课与即时保存。正式图片、教学与考核正文由用户提供；已有课程没有配置时保持原有占位名称和说明。内容人员在 `/content` 使用表单编辑，不需要日常修改代码、SQL 或重新部署。管理员在成员管理中单独授予编辑权限。

## 素材引用

图片字段（iconAssetId、backgroundAssetId、imageAssetId 和内容块／装饰的 assetId）兼容旧素材 ID，现在也直接保存图片地址。编辑器使用链接输入框，支持：

- 仓库图片：将 PNG、JPEG、WebP、AVIF 或可信静态 SVG 放入 `public/course-assets/`，例如 `public/course-assets/chapter-1/map.webp`；部署后填写 `/course-assets/chapter-1/map.webp`。
- 外部图片：填写公开 HTTPS 图片地址；拒绝用户名、密码、查询参数、片段、非 HTTPS 协议和 B2 桶地址，避免把私有作业或临时签名当作课程图片。

本地路径只接受字母、数字、下划线、连字符、目录分隔符与图片扩展名，不接受目录穿越或成员上传路径。服务器只验证链接格式，不请求外部图片；无法保证第三方链接持续可用。客户端显示缺图回退、不发送 Referer。推荐使用仓库路径，新增／替换文件需要重新部署，日常修改已有链接与课程内容仍保存即生效。

`course_asset` 元数据仍用于旧引用，不保存文件。成员响应只返回被可浏览课程引用的合法 published 元数据；直接图片链接随对应可浏览内容返回。旧素材未发布、路径非法、文件缺失或外链加载失败时保留文字和缺图回退。图片正文必须提供替代说明。

**没有网页图片上传。** `public/` 中所有文件都公开，课程归档和数据库状态不会收回静态文件。只放用户授权公开的课程图片，不放成员视频、凭证或其他私密资料。视频独立使用 [B2 私有存储](VIDEOS.md)。

## 章节展示配置

chapter.presentation 为受控 JSON，默认 `{}`；支持以下可选字段：

- iconAssetId：章节图片图标；未配置或缺失时使用原文字图标／顺序。
- backgroundAssetId：固定在画布下方的低对比度背景，不拦截操作。
- viewport：初始 x、y 与 zoom；zoom 范围 0.35–2。手机优先聚焦首个任务以保持可点击尺寸，按类型筛选后重新聚焦任务。
- decorations：最多 100 个图片或文字元素，每项包含唯一 id、position、width、height、layer 和对应内容。图片使用 assetId／alt；文字使用 text。layer 为 0–20，仅决定装饰之间的顺序，所有装饰都在任务和必要连线下方。

坐标范围为 -100000–100000，尺寸必须大于零且不超过 8192。装饰随世界坐标平移／缩放，不参与前置关系、任务总数或个人学习状态，不响应指针操作，也不扩大“回到合适视野”的计算范围。成员仍不能拖动修改节点。

## 任务图文

任务 definition 可附 imageAssetId、content 和 assessmentContent。图片标记在图谱、列表和详情共用；content 为空时显示原 summary，考核内容为空时不显示相应区块。

内容块按数组顺序渲染，最多 100 项，只支持以下类型：

| type      | 字段                       | 显示           |
| --------- | -------------------------- | -------------- |
| heading   | text                       | 内容内小标题   |
| paragraph | text                       | 保留换行的段落 |
| list      | ordered、items             | 有序／无序列表 |
| image     | assetId、alt、可选 caption | 图片与说明     |

标题上限 200 字符；段落和单条列表文字上限 10000 字符；每个列表 1–100 项；图片替代说明上限 300 字符，说明文字上限 500 字符。文字由 React 转义，不解析 HTML、Markdown、脚本、任意 CSS 或外部嵌入。未知内容块及非法章节结构在保存前拒绝。

这些字段只承载展示，不增加考核机制。任务身份、已通过结果和奖励由服务端保留。更改学习要求遵循 [DOMAIN](DOMAIN.md) 的约束；当前对已有学习记录的任务拒绝修改前置或考核内容。

## 即时编辑协议

`GET /api/content/access` 返回独立编辑能力；`GET /api/content/course` 返回完整编辑文档、可选公开素材、版本及有业务记录的任务 ID 聚合 protectedQuestIds，不含成员记录明细。`POST /api/content/course` 提交 expectedRevision、requestId、reason、完整 document 和可选 deletedChapterIds／deletedQuestIds；最大请求 256 KiB，最多 200 章／1000 任务。编辑文档不允许传入奖励设置、个人进度或账号角色。

保存校验全部启用任务的 DAG、章节归属、图片引用和结构。章节和任务删除必须分别明确列入 deletedChapterIds／deletedQuestIds，不能仅从文档省略；删除章节必须同时移除其全部任务，文档、原章节与删除清单须一致。章节内有任一任务存在学习／考核／奖励记录时拒绝删除章节；任务还需要不再被任何任务（包括归档任务）引用。没有记录且无引用时才允许删除，否则使用 archived 隐藏。删除记录保留原章节／任务快照与旧 ID，之后不能重新使用该身份。旧 draft 章节在编辑器按归档处理，只有明确恢复并保存才可浏览。成功后立即整体生效，无提交审批或发布步骤。服务端版本比较与批量写入原子执行，权限和删除资格在写入点再次校验；相同请求重试不会新增版本。`course_change` 留存修改者、时间、原因及整份课程快照，目前无历史浏览或回滚界面。

章节和任务属性都提供删除入口及拦截原因。未保存章节／任务直接从本页移除，已保存内容需确认并在下一次保存时删除；删除章节会连同本章任务。本页提供“撤销删除”，恢复移除前的章节、任务与位置。失败保留本页修改，若内容刚产生记录则提示撤销删除后改用归档。

未保存修改仅保留在当前页面内存，切换站内子页后返回仍保留；关闭／刷新页面会提示，不提供离线持久草稿。桌面与手机预览复用实际图谱、图文与详情组件，但不读取或写入个人学习数据。预览中的图片仍来自已公开课程素材。

## 画布编排

章节设计以画布为主，左侧选择章节，点任务打开属性；成员端的图谱保持只读。画布工具提供放置任务、视野中心新增、框选、连接前置、复制选中及装饰移动；右键空白处也可在该位置新增。触屏及键盘可用可见按钮，前置可依次点选两个任务，方向键移动选中任务，Shift 配合方向键微调。窄屏属性使用可关闭的原生弹层。

移动只改变位置，使用整数坐标并校验范围；任务身份及学习历史不变。复制生成新任务 ID，组内前置改指向对应副本，组外前置保留；不会复制个人进度或奖励登记。连接方向为“前置任务 → 后续任务”，自连、重复或循环在客户端提前处理，保存仍由服务端最终校验。跨章节前置也可在属性面板选择。

属性面板说明主支线仅为路线分类，直接列出当前任务需要通过全部或任意前置。已有学习记录的任务禁用前置和考核字段，画布也提前拦截对其新增／移除前置，服务端仍作最终校验。连线失败在画布旁提示，切换工具清除待连接状态；选中连线显示前置与后续任务名称。手机属性使用全屏弹层，固定关闭入口。

属性和装饰定位使用已有结构，不开放任意脚本／样式；保存方式和独立编辑权限保持不变。2026-10-30 已补充桌面实际拖动、多选、框选、复制、连线、装饰与保存后重载验证，以及 390 × 844 浏览器视口下的新增、点选连接、属性说明和关闭检查；使用隔离课程，没有修改真实课程或个人进度。尚未验证真机触摸手势，详细范围见 [ROADMAP](ROADMAP.md)。
