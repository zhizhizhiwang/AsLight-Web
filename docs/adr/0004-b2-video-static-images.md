# 0004：B2 私有视频与仓库静态课程图片

日期：2026-10-31。状态：按用户要求采用并已部署；真实 B2 存储接口检查通过，网站内视频闭环及真实手机兼容仍待验收。

原方案预选 R2，但尚无已启用的上传后端或对象。用户要求根据其存储讨论改用 Backblaze B2，并让章节图片填写链接、公开图片随仓库部署。

视频使用 B2 Private 桶。小型 aws4fetch 依赖负责 S3 SigV4，浏览器只取得绑定单个对象、大小及类型的五分钟 PUT 授权；服务端确认元数据及容器头后固定版本。Worker 经管理员鉴权代理播放，支持单段 Range；浏览器禁止缓存，Worker 内部按固定版本分段缓存七天，每次访问仍检查权威状态。D1 记录归属、预留配额及删除状态；删除先撤播放权限，再由 Cron 用 Native API 逐版本永久清理，保留审核历史。复用原有通过／退回、不可覆盖尝试和奖励机制，不引入第二套评分数据库。

章节、节点、详情和装饰统一填写图片链接，兼容旧素材 ID。公开图片放在 `public/course-assets/`，由 Vite 与 Workers Static Assets 部署；也接受无凭证 HTTPS 外链。无需开通图片存储桶或新增上传服务。新增图片文件需要部署，已有图片链接和其他课程内容仍通过网页保存即时生效；私有成员视频绝不能随仓库公开。

容量扫描使用 B2 Native API 统计当前文件、历史版本和未完成分片，扫描进度、完整快照及告警历史保存在同一 D1；结合上传预留量原子阻断容量超限。密钥有前缀限制时明确展示统计范围；支持单独的无前缀监控密钥，不自动扩权。

代价：需要独立管理 B2 应用密钥和 CORS；没有自动转码、可信服务端时长检测或账号费用账单统计；外链可能失效。容量扫描存在时点差异，供应商侧仍需配置费用保护。边缘缓存可能提前驱逐，删除通过 D1 立即拒绝后续网站读取，其他地区缓存字节并非全球物理清除。真实存储接口的版本删除已验证；用户反馈跑通一次线上流程，真实手机与新增云端缓存的具体覆盖仍需补充。配置与操作边界见 [VIDEOS](../VIDEOS.md)。
