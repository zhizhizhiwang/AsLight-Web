# ADR 0003：管理员预建成员与无短信登录别称

日期：2026-10-28。状态：已采纳并实现，取代 ADR 0002 的邮件认证流程。

用户明确无需短信／邮件，并接受手机号只作 11 位数字登录别称、不证明号码归属。管理员预建待激活成员并私下交付高熵一次性凭证，成员自行设密码。恢复由管理员人工确认后签发短时凭证。无公开自助建号、角色选择或手机号认领。

保留 Better Auth 的密码与会话，用自定义插件支持无邮箱别称登录；email 真正可空且不向外返回，关闭邮箱及 OTP 端点。D1 batch 原子消费凭证，别称冲突回滚，用户及会话的凭据版本阻断重设竞态下的旧会话。权限和审计由服务端执行。

数据迁移保留内部 user_id、账号密码记录和学习进度；旧会话退出、旧成员需重新激活。避免 D1 父表 DROP 的级联删除，先保留再恢复子表。首次管理员与其恢复只通过受控运维工具。

无需发信域名或短信资质；人工交付和身份确认工作由社团管理员承担。号码回收、误填或冲突不触发自动合并，未来如绑定真实外部身份须另做验证。
